# Changelog

## 1.7 (10.11.2026)
- Update-Prüfung über die Projektseite: beim Start höchstens einmal am Tag (abschaltbar) oder von Hand mit „Jetzt prüfen“
- Hinweis „⬆ Version … verfügbar“ auf der Hauptseite, Dialog mit „Herunterladen“
- Info mit Versionsgeschichte, GitHub-Link und Projektseite
- Hauptseite: Hinweise (Pause, Update) als kleine Chips unter der Ladequelle, Knöpfe unten werden nicht mehr gequetscht
